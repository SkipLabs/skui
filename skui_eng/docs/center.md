# Center

A container that centers its child within itself.

## Properties

| Property       | Type                                       | Default   | Description                                             |
|----------------|--------------------------------------------|-----------|---------------------------------------------------------|
| child          | ?Component or ?Prop`<`Component`>`         | none      | The child component to center.                          |
| configuration  | ?Configuration or ?Prop`<`Configuration`>` | none      | Container configuration properties.                     |
